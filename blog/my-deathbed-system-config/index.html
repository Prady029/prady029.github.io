My Deathbed System Config

A personal blueprint of Linux setups, shell tooling, and reproducible workstation configurations refined after years of distro-hopping.

#linux#fedora#cuda
I am writing this blog in case I come home after soul-searching for a long time of distro-hopping.

Those who know me personally, would always find me experimenting with a lot of new distros and systems. As you could imagine, I do break things a lot and have gone mad a lot of times installing things that doesn’t fit into my schemes..For example, my hadoop system runs on windows 11 with java 16 instead of the same old lame how-to based java 8. I know this sounds like tomfoolery on my part but who learns without breaking systems apart??

What happens when things go wrong?

Well, that what I call my deathbed situation and for that, I do have a plan which I shall share with the world and as a memo to my future self too.

  1. Install fedora (Solus DE is my go-to desktop env). [Fuck you ubuntu for the snap bullshit.]
  2. Now, install zsh and oh-my-zsh:
sudo dnf install zsh 
chsh -s $(which zsh)
sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

3. Configure the zsh theme to ‘agnoster’ and plugins — (git docker)

4. Do what the masters taught you — https://itsfoss.com/things-to-do-after-installing-fedora/ and https://medium.com/@KarolDanisz/things-to-do-after-installing-fedora-39-workstation-cc8eb4090dd1

5. Install Cuda and shit:

https://youtu.be/uyqRe3y7SHc

You are good to go.
